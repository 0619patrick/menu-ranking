# 对账校验说明（输出金额 vs 源数据）

> 配套工具: `scripts/check_menus.py`(改表体检)、预览页黄色警告(实时体检)
> 适用范围: 生成 Excel 前核对「输出合计 ≠ 源数据合计」是否正常

---

## 一、对账口径: 为什么输出 ≠ 源数据是正常的

生成排行表时,**输出合计几乎总是比 POS 源数据合计小**,因为有几类行会被有意排除:

| 排除项 | 配置来源 | 说明 |
|---|---|---|
| 改碼/走/少/多/轉 等辅助分类 | `config.csv` 的 `drop_category` | 不是真实菜品,纯操作记录 |
| 套餐優惠項目 / 套餐類飲品 | 同上 | 套餐内赠送项,金额为 0 |
| 金额 = 0 的行 | 菜单 `drop_zero_amount` | 纯赠送/纯退菜,无营收 |
| 打包盒/纸巾等周边 | `drop_name` | 非菜品 |

**对账公式**:

```
预期输出金额 = 源数据金额合计 − drop 分类金额合计 − 被丢弃的金额=0 行(贡献 0)
```

如果 `实际输出金额 == 预期输出金额`,对账即通过。

## 二、差额对不上时,按这个顺序排查

### 1️⃣ 先看预览页有没有黄色警告条

警告条 = **同一个 POS 写法被两道菜引用** → 该写法的销量/金额会被算两遍,
导致 `实际输出 > 预期输出`(金额**偏大**,方向正好和正常排除相反)。

**典型案例**(2026-08 实测发现):
- 天天「新加坡原味豆腐花」把 `新加坡原味豆腐花加美祿` 也挂在 POS 写法里,
  和「新加坡原味豆腐花加美祿」这道菜重复 → 多算 725 元
- 阿城「滷味拼盤」把 4 个 25g 单品写法(滷鵝肝/胗/腸/心)都挂上,
  和「15元滷味精選小食」下的单品重复 → 多算 11,862 元

**修复**: 把重复的写法从其中一道菜里删掉,只保留唯一归属。
跑 `python scripts/check_menus.py` 可一次性列出所有冲突。

### 2️⃣ 检查外卖金额是否被截断

`build_delivery` 处理外卖行时,金额若用 `int()` 直接截断,
88折 等折扣价(如 1525.92)会变成 1525,小数部分丢失。
多行累积可差出十几元(v1.5 已改为 `int(round(...))` 四舍五入)。

**表现**: 输出比预期**小**,且差额 ≈ 各外卖行金额小数部分之和。
**排查**: 找源数据里含小数的外卖行(`金額 != int(金額)`),求和比对。

### 3️⃣ 检查手寫單/補差價负金额行

POS 里「手寫單」等補差價分类是**负金额**(-5、-24 …),属正常业务:
- 它们会进「堂食菜單外」或外卖 adjustments,不参与排行主表
- 对账时负金额行会拉低合计,差额方向取决于它们被归到哪块

**不要**试图「修正」负金额——那是补差价的真实记录。

### 4️⃣ 检查金额=0 但数量>0 的行

如「2人餐套餐項目」「ODO飲品(不能撞餐)」:
- 数量几百上千,但金额为 0(套餐内含/赠送)
- `drop_zero_amount` 会整行丢弃 → 数量对不上,但金额不受影响

**对数量对账时**必须把这部分算进排除项,否则会误以为数据丢了。

## 三、快速对账脚本

本地跑(替换路径/餐厅 key):

```python
import io, re
from app.core.transformer import load_source, build_preview_data
from app.services.menu_service import get_menu

src = load_source(io.BytesIO(open('源文件.xlsx','rb').read()), 'canyinwang')
menu = get_menu('tiantian')
pv = build_preview_data('测试店', src, menu)

out_a = (sum(i['amt'] for s in pv['menu'] for i in s['items'])
       + sum(i['amt'] for s in pv['extras'] for i in s['items'])
       + sum(i['amt'] for i in pv['tea'])
       + sum(i['amt'] for pl in pv['delivery']
             for s in pl['normal']+pl['selftake'] for i in s['items'])
       + sum(i['amt'] for pl in pv['delivery'] for i in pl['adjustments']))
src_a = int(src['金额'].sum())
pat = '|'.join(re.escape(m) for m in menu.all_delivery_markers)
drop_a = int(src[src['分类'].isin(menu.drop_categories or [])]['金额'].sum())
diff = out_a - (src_a - drop_a)
print(f'差额: {diff:+d} 元  警告: {len(pv["warnings"])} 条')
# diff == 0 且 warnings 为空 → 对账通过
```
